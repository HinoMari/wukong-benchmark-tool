# Инженерные заметки

## Условия разработки

Решение писалось без установленного Black Myth: Wukong Benchmark Tool (его нет в Steam-
библиотеке машины, на которой велась разработка), и официального описания формата результатов
бенчмарка нигде не нашлось. Поэтому ниже — честное разделение на то, что проверено, и то, что
нет.

Также: в открытом доступе уже есть минимум два чужих решения этого же (судя по всему,
хорошо известного) задания — `EgorZarame/vk-tech-task-1-wukong-benchmark` и
`CaseyJohnson-RS/Black-Myth-Wukong-Benchmark-Tool-Automatization` на GitHub. Ни один из них не
открывался и не использовался как основа для этого кода.

## Подтверждено документированным поведением (не требует калибровки)

- Steam AppID инструмента — `3132990`; путь к установке находится через реестр
  (`HKLM\SOFTWARE\WOW6432Node\Valve\Steam`/`HKCU\SOFTWARE\Valve\Steam`) + `libraryfolders.vdf`
  + `appmanifest_3132990.acf` (`Steam/SteamLocator.cs`) — проверено на реальной установке Steam.
- `GameUserSettings.ini` лежит в `.../Saved/Config/<Windows|WindowsNoEditor>/` — стандартная для
  UE4/5 структура; код ищет по обоим вариантам защищённо (`Steam/SteamLocator.cs`).
- Секция `[/Script/Engine.GameUserSettings]` и ключи `ResolutionSizeX/Y`, `FullscreenMode`,
  `bUseVSync`, `FrameRateLimit`, `sg.*` — стандартный для всех UE4/5-игр набор
  (`Benchmark/IniSettingsWriter.cs`).
- Встроенный в Unreal Engine **CSV Profiler** (`-csvCaptureFrames`, `-csvGpuStats`, вывод в
  `Saved/Profiling/CSV/*.csv`) — задокументированный, не зависящий от конкретной игры механизм.
  Метрики (средний FPS, 1% low, мин/макс) считаются в коде из `FrameTime` самостоятельно
  (`Benchmark/CsvResultParser.cs`), а не из недокументированного "экрана результатов" самого
  инструмента.
- Сбор характеристик ПК через WMI (`SystemInfo/HardwareInfoCollector.cs`) — проверено на реальной
  машине.

## Требует калибровки на живом запуске (единственная непроверенная часть)

Какой конкретно экран/кнопку нужно нажать, чтобы стартовал сам прогон бенчмарка после применения
настроек — не задокументировано нигде. Решение: вместо того, чтобы гадать координаты, которые
скорее всего были бы просто неверны, инструмент умеет **записать реальные шаги один раз вручную**
(`wukong-bench calibrate`, `Benchmark/CalibrationRecorder.cs`) — опрашивает глобальное состояние
левой кнопки мыши и клавиш Enter/Escape/Space/стрелок/Tab, пока человек один раз проходит меню,
и сохраняет последовательность в `calibration.json`. Дальнейшие прогоны используют её
автоматически (`Benchmark/MenuNavigator.cs`). Без файла калибровки используется плейсхолдер из
двух нажатий Enter с паузами — он может случайно сработать, но полагаться на это не стоит.

Сигнал "прогон завершён" определяется эвристически: CSV-файл перестал расти 20 секунд подряд,
либо процесс завершился сам, либо общий таймаут 20 минут (`Benchmark/BenchmarkRunner.cs`,
`WaitForBenchmarkCompletionAsync`) — это сознательный компромисс при отсутствии официального
события "бенчмарк окончен".
