# Wukong Benchmark Tool — автопрогон CPU/GPU

C#-утилита, которая без участия человека прогоняет **Black Myth: Wukong Benchmark Tool**
(Steam, AppID `3132990`) дважды — с настройками, выявляющими упор в CPU, и с настройками,
выявляющими упор в GPU, — собирает характеристики ПК и FPS-метрики каждого прохода и пишет
читаемый отчёт.

## Предпосылки

- Windows 10/11.
- Steam, установленный и хотя бы раз запущенный (чтобы были созданы конфиги).
- **Black Myth: Wukong Benchmark Tool** (AppID `3132990`) установлен через Steam и хотя бы
  один раз запущен вручную до главного меню — это создаёт `GameUserSettings.ini`, без которого
  утилите нечего патчить.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) для сборки/запуска.

## Важная оговорка

Инструмент написан и собран **без доступа к самому Benchmark Tool** (его нет в локальной
Steam-библиотеке, на которой велась разработка) — см. `docs/DESIGN.md` за подробностями. Это
не меняет сути решения, но означает, что часть логики — навигация по меню до старта прогона —
не могла быть проверена вживую и требует одной короткой ручной калибровки перед первым
«боевым» запуском (см. ниже). Всё остальное (поиск установки Steam, чтение/запись
`GameUserSettings.ini`, сбор характеристик ПК, получение и разбор метрик FPS) опирается на
задокументированное поведение Steam и Unreal Engine и в калибровке не нуждается.

## Как это работает

1. Снимает характеристики ПК (CPU, GPU, RAM, ОС, разрешение экрана) через WMI.
2. Находит установку Benchmark Tool: путь к Steam — из реестра, библиотеку и `installdir` —
   из `libraryfolders.vdf` и `appmanifest_3132990.acf`.
3. Делает бэкап `GameUserSettings.ini`.
4. Для **CPU-теста**: выставляет 1280×720, оконный режим, все настройки графики (`sg.*`) на
   минимум, трассировку лучей выключает, апскейлинг выключает (рендер в 100% разрешения) — это
   снижает нагрузку на GPU, но не на CPU (логика игры, ИИ, физика и число draw call'ов не
   зависят от разрешения/качества картинки), поэтому узким местом остаётся процессор.
5. Запускает прогон через `steam.exe -applaunch 3132990 ...` с флагами встроенного в Unreal
   Engine **CSV Profiler'а** (`-csvCaptureFrames`, `-csvGpuStats`) — метрики считаются из
   получившегося CSV (`Saved/Profiling/CSV/*.csv`) самим инструментом, а не выводятся из
   недокументированного "экрана результатов" самого Benchmark Tool.
6. Для **GPU-теста**: выставляет нативное разрешение экрана, все `sg.*` на максимум, трассировку
   лучей на максимум, апскейлинг выключен (нативный рендер) — максимальная нагрузка ложится
   именно на видеокарту при той же нагрузке на CPU.
7. Восстанавливает исходный `GameUserSettings.ini`.
8. Пишет отчёт в `reports/report-<дата>.md`: характеристики ПК + настройки и метрики (средний
   FPS, 1% low, мин/макс, при наличии — отдельно GPU) каждого прохода.

## Калибровка навигации по меню (один раз, вручную)

Способ "нажать Start" в UI Benchmark Tool не задокументирован и не мог быть проверен без самого
инструмента. Перед первым прогоном запишите реальные шаги один раз:

```bash
dotnet run --project src/WukongBenchmarkTool -- calibrate
```

Утилита запустит Benchmark Tool и будет слушать ваши клики мышью и нажатия Enter / Escape /
Space / стрелок / Tab, пока вы вручную не дойдёте до старта прогона. Нажмите `Q` в консоли,
чтобы закончить и сохранить `calibration.json` рядом с собранной утилитой. Дальше обычный
прогон будет использовать эти шаги автоматически.

Без `calibration.json` используется плейсхолдер (два нажатия Enter с паузами) — он может
сработать случайно, но рассчитывать на это не стоит.

## Запуск

```bash
dotnet run --project src/WukongBenchmarkTool
```

Прогон займёт столько же времени, сколько два ручных прохода бенчмарка подряд (плюс время на
загрузку/рестарт между ними). По завершении путь к отчёту печатается в консоль.

## Структура проекта

```
src/WukongBenchmarkTool/
  SystemInfo/   — сбор характеристик ПК (WMI)
  Steam/        — поиск установки Steam/Benchmark Tool (реестр + VDF)
  Benchmark/    — профили настроек, патч ini, запуск прогона, калибровка меню, разбор CSV
  Report/       — Markdown-отчёт
  Native/       — P/Invoke для симуляции ввода и работы с окнами
  Program.cs    — точка входа (`run` и `calibrate`)
```
